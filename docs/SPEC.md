# Forever Hub — спецификация

Личный хаб для WoW: Forever (официальный сервер Blizzard, кап 60, таланты на системе Trait,
аккаунтовая система Legacy). Сначала для владельца и гильдии, без монетизации. Хобби-проект.

Источник требований — брейншторм от 4 ноября 2026 и прототип Forever Hub (код в `legacy/`).

## Профиль игрока (влияет на приоритеты)

- Ruleset PvP, фракция Орда.
- Персонажи: **Жрец** → **Разбойник** (разница ~40 уровней) → Паладин или Воин (пока не решено).
- Приоритеты: PvP (открытый мир, БГ; арены не нужны) = прокачка → рейды и данжи → профессии и золото
  (качать вместе с уровнями) → коллекционирование (но важно знать о коллекционке, доступной только
  на низких уровнях, до 60).
- Начинает соло, потом гильдия (не ГМ и не зам). Нужны инструменты для участника гильдии.

## Общие требования

| Тема | Решение |
|---|---|
| Доступ | Вход обязателен. Один суперадмин (владелец); роль `member` заложена для гильдии |
| Языки | RU и EN сразу, позже грузинский (`ka`): словари в `frontend/src/lib/i18n.tsx` |
| Темы | По фракции и расе. Старт: **Нежить** и **Орда**. Тёмный современный UI с эффектами и анимацией |
| Звуки | По теме (раса/фракция), отключаются, по умолчанию выключены |
| Устройства | Десктоп в приоритете, мобильная вёрстка должна быть годной |
| Ассеты | Для личного использования берём иконки и фоны Blizzard; при публикации заменим |
| Хостинг | Сначала локально, потом Railway (сейчас ~7 $/мес) |
| CI | GitHub Actions: тесты, линтеры, сборка |
| Аддон | Позже. Только легальное: SavedVariables → ручная загрузка файла (кнопка «Обновить»). Никаких инжектов, чтения памяти, автоматизации действий в игре |

## Модули и приоритет

**Сейчас: калькулятор, дашборд и статус.** Остальное — когда появится официальный API
(или через аддон).

### 1. Калькулятор талантов (главный модуль)

Переносим логику прототипа **один в один**, на TypeScript с тестами (`frontend/src/engine`).

- Правила: очки с 10 уровня, кап 51; сетка 7×4; требование ряда 5/10/…/30; стрелки (родитель
  вкачан полностью); добавить и убрать только если билд остаётся допустимым; `fixGates`.
- План прокачки (`order`): уровень каждого очка, `normOrder`, `rowOrder`, `orderProblem`,
  перестановка блоков, просмотр дерева на уровне, способности тренера по уровням.
- Ссылки: формат прототипа читается всегда; новый формат v2 добавляет номер сборки
  (`t2-<класс>-B<сборка>-L…`).
- Сохранённые билды: на сервере, по ID узлов с отпечатком `fp`; проверка на новой сборке
  (`analyzeSave`), «Сохранить исправленный», сравнение.
- **Legacy полностью**: все три дерева (1187–1189, валюта 4225, до 16 очков) с проверкой условий
  открытия и привязкой к аккаунтовому прогрессу из трекера.
- Заметки Blizzard и предпросмотр по заметкам — оставить (уникальная фича).
- **Импорт и экспорт игровой строки билда** — в приоритете, как только станет известен формат.
- **Библиотека билдов** — полноценная: теги (прокачка, PvP, рейд, фарм), поиск, фильтр по классу.
- **Экспорт билда картинкой** для Discord и Telegram.
- **Учёт экипировки и статов в подсказках** (реальные цифры с силой атаки и заклинаний) —
  включаемая опция.
- Пока не нужно: чужие билды, комментарии, форки.

### 2. Дашборд и статус

- Статус сервера и работ (живой, через SSE), отсчёт до ресета (EU и US), синие посты,
  персонажи, золото.
- Переносим из прототипа целиком: статус, диффы талантов, синие посты, база кодов ошибок.
- Метрики сервера (население, баланс фракций, очереди) — интересны, но не в приоритете.

### 3. Трекер (после API или аддона)

Отслеживать: экипировку и список BiS; профессии и рецепты; кулдауны (трансмуты, данжи);
репутации; аттюнменты; рейд-локауты и ресеты; квестовые цепочки; челленджи и очки Legacy;
золото по персонажам; игровое время и сессии; свои цели и чеклисты.
Уровень и опыт не обязательны. История не нужна, хватит текущего состояния.

### 4. Золото и фарм

- Первым делом **журнал фарма** и **таймеры**.
- Способы: фарм мобов и локаций, профессии и крафт, гринд данжей.
- Базы мобов, лута и точек фарма **на карте** (типа OpenMap: Leaflet с тайлами карт мира)
  с ручными заметками.
- Аукцион — потом.

### Потом

Telegram-бот, MCP-сервер, AI-аналитика — не трогаем, пока не дойдём.
